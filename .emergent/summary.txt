**Key Technical Concepts**
-   **RBAC (Role-Based Access Control)**: Implemented in FastAPI using enums for roles and dependency injection for permission checks on API endpoints. Includes a concept of protected Super Admins.
-   **Audit Logging**: Storing records of all admin actions in a dedicated MongoDB collection.
-   **Conditional Rendering (Frontend)**: Using user's subscription and application status to dynamically change UI and navigation (e.g., Fund Management vs. Investor Dashboard).
-   **Hybrid API-UI Flow**: Implemented a flow where a frontend action (e.g., tapping a button) first triggers a backend API call to create a database record, and upon success, triggers a UI action (e.g., opening a WhatsApp deep link).
-   **Startup Tasks (Backend)**: Using FastAPI's  to ensure Super Admin accounts are always present and correctly configured in the database.
